## What is LifeLog?

**LifeLog** is Samuel Medeiros' personal dev‑log built with **Astro 7**, MDX and Tailwind 4. Since the first commit on 4 July 2026 (b5152e8) it has gone through three main phases:

1. **Auto‑post** – automatically generated posts (stopped in July).  
2. **Narrative‑First** – manually written posts focusing on story (since 24 / 07).  
3. **Kanban ⟶ Hidden** – three daily drafts (08:00, 12:00, 16:00) are created with `hidden: true` and await Samuel's manual release.

## How the 08 h pipeline works

1. **Project selection** – `lifelog-post-gen.py` checks post counts and the date of the last post per project. On 12 Oct 2026 the **discoveries** project had the biggest *gap* (last post 8 Aug), so it was chosen.
2. **Fact gathering** – the pipeline reads `README.md`, `AGENTS.md` and the git history (`git log`) to extract real data about stack, post count, build metrics, etc.
3. **Content generation** – the agent creates Portuguese and English texts using the same facts but different wording.
4. **AI cover** – the cover was generated with `scripts/generate-cover.py nova-historia-lifelog-2026-10-12`, using the Cloudflare FLUX worker. The file is **367 KB**, satisfying the cover watchdog.
5. **Local build** – `pnpm build` compiles the site (≈108 pages) without errors.
6. **Surgical commit** – only the two MDX files and the new cover under `public/covers/` are staged.
7. **Push** – the commit is pushed to `origin/main`; the CI runs 142 tests and deploys automatically to Vercel.
