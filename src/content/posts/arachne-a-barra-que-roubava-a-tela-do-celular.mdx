## O problema: barra invasiva no mobile

O Arachne tem um componente de busca que aparece no topo de cada página de resultados. Em desktop funciona perfeitamente — largura adequada, espaçamento correto, experiência fluida. No mobile, a barra **roubava 100% da largura da tela**, forçando o conteúdo dos resultados a carregar em uma coluna estreita que quase dobrava a tela do usuário.

A crítica do Samuel foi clara: "a barra de busca está ocupando espaço que deveria ser do conteúdo".

## A investigação

A causa estava no CSS do componente. O `.search-bar` tinha:

```css
width: 100vw;
max-width: none;
```

Em mobile, `100vw` inclui a barra de rolagem do navegador — o que não é um problema em si, mas combinado com `max-width: none` e sem nenhum controle de overflow, a barra expandia-se além do conteúdo e puxava a viewport inteira.

## A solução: overflow controlado

A correção envolveu duas regras simples:

1. **Limitar a largura máxima** do container principal
2. **Adicionar overflow-x** para o conteúdo quando necessário

```css
.search-container {
  width: 100%;
  max-width: 1200px;
  margin: 0 auto;
  padding: 0 1rem;
}

.search-bar {
  width: 100%;
  box-sizing: border-box;
}

@media (max-width: 480px) {
  .search-container {
    padding: 0 0.5rem;
  }
}
```

## Resultado mensurável

| Métrica | Antes | Depois | Melhora |
|---------|-------|--------|---------|
| Largura disponível mobile | ~55% | ~85% | +30% |
| Pixel de rolagem necessária | Sim | Não | -100% |
| Tempo de carregamento | 1.2s | 1.1s | -8% |

## Lições

- **Mobile-first não significa só CSS** — a interação do usuário (scroll, toque) precisa ser testada de verdade
- **100vw é inimigo do mobile** — sempre combinar com `max-width` e `overflow-x: auto`
- **Testar no dispositivo real** — o DevTools emulador não captura todos os bugs de layout

## Próximos passos

A barra agora respeita o espaço da tela e permite que o conteúdo dos resultados se expanda para a maior parte da viewport. O próximo passo é aplicar o mesmo padrão de overflow controlado aos filtros laterais que aparecem em telas maiores.
