## O pipeline que existe de verdade

Não é um cron que escreve sozinho. É uma cadeia de scripts que roda no build e no
release, cada um barrando um tipo de defeito:

```
node scripts/validate-covers.mjs      # todo post precisa de capa que existe
node scripts/gen-ocultos.mjs          # gera api/ocultos-data.mjs a partir dos hidden
astro build                           # build estático
node scripts/gen-preview-data.mjs     # HTML do preview de post oculto
```

Se qualquer etapa falha, o build para. É por isso que post sem capa não sobe — o
`validate-covers.mjs` foi criado em 23/08/2026 exatamente depois de um post WCAG
subir com o `.webp` gerado e sem a linha `cover:` no frontmatter.

## O que consertou a lista de ocultos

O `/ocultos` lia o filesystem do deploy. Em bundle da Vercel o filesystem não é o
do repo, então a lista vinha vazia. A cura foi gerar os dados no build e a função
só servir o que já estava em memória:

```
api/ocultos.mjs  ->  import OCULTOS from './ocultos-data.mjs'
```

Mesma família de problema no preview: o HTML de cada post oculto passou a ser
gerado no build (`gen-preview-data.mjs`) em vez de renderizado sob demanda.

## O buraco que ninguém estava cobrindo

Até hoje o pipeline verifica **estrutura**: capa existe, tag está no vocabulário,
frontmatter tem os campos, PT e EN estão sincronizados, saída tem UTM.

Nada verificava se o que o texto afirma é **verdade**. Um post podia citar um
commit que não existe, um script que nunca foi escrito, uma tabela de métricas
inventada — e subia igual, porque nenhum gate olhava para isso.

O antídoto é mecânico, não opinativo: se o post cita um commit, o SHA tem que
existir em algum repo do ecossistema; se cita um arquivo, o caminho tem que
existir — ou ter existido, porque arquivo removido depois não torna o post
mentira. Número e path são checáveis; opinião não. O que não pode ser verificado
pela máquina não entra como se fosse fato.

## O que ficou de pé

- Capa: gate no build, auto-fix quando o `.webp` existe e a linha `cover:` falta
- `/ocultos`: dados gerados no build, lista nunca mais vazia
- Preview de oculto: HTML estático por post, sem depender de runtime
- Liberação: commit atômico com MDX PT+EN + ocultos-data num commit só
- Verificação de fato: era o que faltava — agora é gate de build
